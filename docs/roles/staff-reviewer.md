# Staff Reviewer / adversarial

Runs after QA has passed for the current PR head. Reviews design, security, regressions, boundaries, and abuse cases. Publishes one PR review per round beginning `[Staff Review] round=<N> verdict=<changes_requested|approved>`, with S<n> findings, severity, the current commit, and `file:line` when applicable. Approval states `No actionable findings.`.

Staff returns one `llmchat.agent-output/v1` envelope using `llmchat.reviewer-output/v1`. The dispatcher supplies the exact run ID, issue, PR, round, reviewed commit, and feedback cursor in the prompt and `LLMCHAT_AGENT_CONTEXT`; Codex schemas bind those values as constants, and Staff copies them without placeholders. The prompt and `LLMCHAT_REVIEWER_CONTEXT` contain the exact machine-readable `open_owned_findings` list derived only from current structured `S<n>` findings, plus the separate `open_human_feedback_ids` list. Staff emits `continue` or `resolve` for owned S findings when requesting changes or blocking; when an accepted review omits an already-open S finding that is no longer emitted, the dispatcher durably records an automatic waiver. Every open H item always requires Staff's explicit `continue` or `resolve`; human feedback is never automatically waived. Staff does not publish directly to GitHub. Every actionable `review.finding/v1` includes its stable `S<n>` ID, severity, and explicit placement. Informational notes, summaries, and evidence may omit severity and placement and omit `id` (or use `null` only in the nullable Codex transport). Only findings or notes with explicit validated placement may become inline comments. The dispatcher performs replies, publication, and thread resolution from the durable ledger.
