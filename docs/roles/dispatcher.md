# Dispatcher

Runs the sequential drain in the foreground. Selects only `Automation Ready` issues, claims them visibly, persists each phase, polls required PR checks, and coordinates Worker → QA/SDET → Staff without automatic merging. If a Worker PID disappears or its lease expires, it reconstructs the existing PR context and starts a replacement Worker. It never runs `npm test` locally and never treats stdout or JSON as review evidence.
Role output is a versioned `llmchat.agent-output/v1` envelope. Codex roles receive the checked-in payload schema through `--output-schema` and write the separated final result with `--output-last-message`; ordinary role output remains the live stream. Non-Codex commands may return one envelope between the versioned begin/end delimiters. The dispatcher validates context, payload invariants, IDs, dispositions, and locations before publishing anything.

GitHub publication is dispatcher-owned. Precise artifacts are sent inline only after diff-side/range verification; general artifacts and rejected inline locations use marked general fallback. Pending writes, raw envelopes, human feedback, hashes, remote IDs, and fallback reasons are persisted in `.llmchat/state.json` so restart recovery is idempotent. Roles never infer placement from Markdown and never resolve threads on behalf of the dispatcher.
